# ریشه ۲ — سیستم عملیاتی کسب‌وکار

ریشه یک کسب‌وکار نوپای کوچک در حوزه تأمین، بسته‌بندی و فروش محصولات کشاورزی و غذایی است. این افزونه برای جریان واقعی همین کسب‌وکار طراحی شده است، نه به‌عنوان یک ERP عمومی و سنگین.

## اصل محصول

- **ووکامرس مرجع محصول، مشتری و سفارش است.**
- **ریشه مرجع موجودی چندانباره، تأمین، بسته‌بندی، مالی، لجستیک و B2B است.**
- محصول، مشتری یا سفارش ووکامرس دوباره داخل ریشه ثبت نمی‌شود.
- فروش سایت، ایونت، دکان و B2B در نهایت به سفارش ووکامرس تبدیل می‌شود.
- ریشه موجودی قابل‌فروش را محاسبه و با ووکامرس همگام می‌کند.

## شش جریان اصلی

1. انبار و بسته‌بندی
2. فروش و بازاریابی
3. بازرگانی و تأمین
4. مالی و حسابداری
5. لجستیک
6. فروش B2B

## نسخه ۲.۰.۰

نسخه ۲ رابط روزمره افزونه را از فرم‌های فنی ERP جدا می‌کند و یک مرکز فرمان اقدام‌محور ارائه می‌دهد:

- داشبورد فروش، سفارش‌های نیازمند پیگیری، کمبود موجودی، خرید و ارسال
- اتصال مستقیم به سفارش‌ها، محصولات و مشتریان ووکامرس
- موجودی لحظه‌ای، ورود کالا و انتقال بین انبارها با انتخاب نام کالا و انبار
- سفارش خرید ساده و پرونده تأمین‌کننده
- سند افتتاحیه مرحله‌ای و خروجی موقت تراز آزمایشی، سود و زیان، ترازنامه، جریان نقد و حقوق مالکانه
- نقش‌های آماده برای مالی، بازرگانی، انبار، فروش، B2B، لجستیک، شعبه، صندوقدار و مشاهده‌گر
- رابط فارسی، راست‌چین، واکنش‌گرا و مناسب موبایل
- حفظ ابزارهای تخصصی قبلی به‌عنوان لایه پیشرفته، بدون شلوغ‌کردن منوی روزمره

## پیش‌نیازها

- WordPress 6.5+
- PHP 8.1+
- WooCommerce برای جریان محصول، مشتری و سفارش
- MySQL 8 یا MariaDB 10.6+

## ساخت بسته نصب

```bash
composer install --no-dev --optimize-autoloader
mkdir -p build/rishe
rsync -a ./ build/rishe/ --exclude '.git' --exclude '.github' --exclude 'build' --exclude 'tests'
cd build && zip -qr rishe-2.0.0.zip rishe
```

GitHub Actions نیز در هر Push یا Pull Request بسته نصب `rishe-2.0.0.zip` را به‌عنوان Artifact تولید می‌کند.
